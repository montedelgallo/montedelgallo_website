{%- comment -%} Language switch: the current language as plain text, every other language as a link to THIS page in that language. When the page has no version in that language the link goes to that language's home instead, so it never dangles. Included by header.html. The links are wrapped in static_href so that jekyll-polyglot leaves them alone: it would otherwise put the current language's prefix on them (an English link on the Italian page would become /it/...). {%- endcomment -%} {%- assign here = site.active_lang -%}
