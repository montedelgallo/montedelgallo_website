{%- comment -%} The team grid: one tile per member, a square portrait, an optional badge (Founder, Co-Founder), the name and the role, in two rows: the founders (ul.team--founders) and the team (ul.team--members). Used by the home (the team section) and the About hub (about.html, it/chi-siamo.html). {% raw %}{% include team-grid.html %}{% endraw %} The people are _data/team.yml: founders: (row 1) and members: (row 2), in the order of the file, each with a role (and badge) in both languages: the include prints the language of the page (its `lang`, or the language being built for a single-source page). Each row is a list with an accessible name (groups: in the data, per language); a list with no entry prints no row. A member with a `photo` shows it as an with alt text ("Portrait of ", see portrait: in the data) and its size, so the page does not jump when it loads; a member without one gets a tile with their initials, drawn in the blueprint style of the site (no stock picture, no generated face). Optional parameters `founders` and `members`: lists of the same shape, instead of the data file (the build check uses them to prove the tile and the two rows); when `members` is given, the founders row is `founders` alone (none, if it is not given). A portrait is never shown wider than its own pixel width: the carries style="max-width:px" (the stylesheet draws a tile as wide as its column, at most 260px, the width of the smallest real portrait, so the tiles are all the same size and none is stretched; script/check-build.sh asserts both). The initials are the first letter of the first and of the last word of the name ("Ada Lovelace" is AL, "Grace" is G).
