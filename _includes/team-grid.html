{%- comment -%} The team grid: one tile per member, a square portrait, an optional badge (Founder, Co-Founder), the name and the role. Used by the About hub (about.html, it/chi-siamo.html). {% raw %}{% include team-grid.html %}{% endraw %} The members are _data/team.yml (members:), in the order of the file, each with a role (and badge) in both languages: the include prints the language of the page (its `lang`, or the language being built for a single-source page). A member with a `photo` shows it as an with alt text ("Portrait of ", see portrait: in the data) and its size, so the page does not jump when it loads; a member without one gets a tile with their initials, drawn in the blueprint style of the site (no stock picture, no generated face). Optional parameter `members`: a list of the same shape, instead of the data file (the build check uses it to prove the tile). A portrait is never shown wider than its own pixel width: the carries style="max-width:px" (the stylesheet draws every tile at most 140px, the width of the smallest real portrait, so the tiles are all the same size and none is stretched; script/check-build.sh asserts both). The initials are the first letter of the first and of the last word of the name ("Ada Lovelace" is AL, "Grace" is G). This include prefixes every variable it assigns (tg_): an include shares the variables of the page that includes it, and Liquid's `assign` is global, so an `assign t`, `lang` or `p` here would replace the page's own with no error (see the rule in index.html, and the canary in script/check-build.sh). {%- endcomment -%} {%- assign tg_lang = page.lang | default: site.active_lang -%} {%- assign tg_members = include.members | default: site.data.team.members -%}
