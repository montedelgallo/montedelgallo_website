{%- comment -%} Everything inside , for every page: title, description, canonical URL, hreflang alternates, Open Graph / Twitter, font preloads, stylesheet. Front matter a page can set: title, meta_title, description, image (see _data/site_meta.yml), and noindex: true (a draft page: robots noindex; pair it with sitemap: false). A page that sets none gets the site defaults of its language. A collection item that has a `summary` (a project) uses it as its description when it sets no `description`, so its page does not repeat the home page's. Canonical and hreflang are written here and not with polyglot's I18n_Headers tag: that tag finds a page's other languages only through `lang:` + `page_id:` front matter, so for the single-source home (one file, rendered once per language) it leaves out the Italian alternate. lang-url.html knows both kinds of page.
