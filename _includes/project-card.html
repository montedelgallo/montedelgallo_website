This include assigns no variable the page could own (only pc_eager and pc_priority, and picture.html's pic_*), and must stay that way: Liquid's `assign` is global, and an include shares the variables of the page that includes it. An `assign t = ...` here would replace the page's own `t` (the whole i18n tree, see index.html) and every section rendered after the cards would read the wrong thing and print blanks, with no error. So it reads include.project directly. script/check-build.sh has a canary for this. The cover is a responsive picture (_includes/picture.html: srcset from the manifest, its size reserves the space, every cover is 1200x675). It is lazy-loaded unless the caller passes `index=`: the first three cards (the first row of an index page) are eager and the very first has fetchpriority=high. The home passes no index: all lazy. The alt text is `cover_alt`, which describes the picture, and falls back to the title. The link is written as a plain root-relative path: in the Italian build jekyll-polyglot puts /it/ in front of it.
