{%- comment -%} The top of every page: the utility strip (location, phone, language switch) and the sticky navigation (brand, links, booking button). The links come from _data/nav.yml, their labels from _data/i18n/.yml. On a phone (below 860px) the links, the language switch and the booking button live in #site-menu, which the button .nav__toggle opens and closes (assets/js/nav.js, styles in _sass/foundry/_shell.scss). The menu is collapsed only when the page has ; without JavaScript (or when nav.js fails to load or throws, which both put the class back to no-js) it is simply open. The language switch is in the utility strip on a desktop and in the menu on a phone. The booking button exists twice so that it stays one tap away on a phone: .nav__book in the bar (phone only, short label) and the one in .nav__cta (desktop only); only one is displayed at a time, so there is never a double tab stop.
